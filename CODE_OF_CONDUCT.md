# Davranış kuralları

Bu proje mesleki bir araçtır; katkı sürecinde ölçülü, teknik ve saygılı iletişim beklenir.

- Kişisel saldırı, ayrımcılık, taciz kabul edilmez.
- Hukuki tavsiye niteliğinde iddia üretilmez; tartışma kaynak ve test üzerinden yürür.
- Güvenlik açığı bildirimi kamuya açık issue olarak değil, `SECURITY.md` yolundan yapılır.
- İhlal bildirimi: maintainer'a özel mesaj. Gizlilik esastır.

Uygulama: uyarı → katkı askıya alma → kalıcı yasak. Karar maintainer'larda, gerekçesi kayıtlıdır.
